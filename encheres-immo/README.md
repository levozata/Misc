# Enchères Immo · France

Static site: upcoming French court-ordered property auctions (Licitor snapshot, 12 Oct 2026) with map, calendar, search, price model and cost calculator. FR / EN / TR.

- `index.html` – the app (no build step)
- `data.json` – listings, model and past sales
- `dep.json` – département boundaries
- `photos/` – crops from published bailiff reports (Ferrari Publicité watermark)
